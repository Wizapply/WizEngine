# UI の XML の書き方（`<canvas>` と要素）

シーン文書（`assets/scenes/*.xml`）に、画面の上の UI と、3D の空間・カメラの前に置く UI の板を
書くための説明書です。見本は `assets/scenes/ui.xml`（共用 UI は `assets/ui/hud.xml`）。

書式の正はコードの表です。この説明書と表が食い違ったら、表が正しいものとして扱ってください。

| 何の表か | 場所 |
|---|---|
| 要素の性質（属性） | `src/ui/UiProps.cpp` の `kProps` |
| Canvas の属性 | `src/ui/UiTypes.h` の `kCanvasAttrs` |
| 要素の種類 | `src/ui/UiKinds` |
| 読み書き | `src/ui/UiXml` |

ブラウザの Inspector の欄も、同じ表から作っています（`/scene` の `ui.schema`）。

## 1. 全体の形

```xml
<wizengine model="example" version="4">
  <asset>
    <font name="jp" file="fonts/NotoSansJP-Regular.otf"/>  <!-- 書かなければ同梱の Noto Sans JP -->
    <ui name="hud" file="ui/hud.xml"/>                     <!-- 共用 UI（中身はファイル） -->
    <ui name="menu"> <image .../> ... </ui>                <!-- このシーン専用の UI -->
  </asset>
  <worldbody>
    <canvas name="title" order="1">                         <!-- 映像の上に重ねる（overlay） -->
      <image id="1" name="panel" pos="32 32" size="760 364" color="0 0 0 0.4"/>
      <text id="2" parent="1" name="heading" pos="28 20" size="704 80" text="見出し"/>
    </canvas>
    <canvas name="hud" ui="hud"/>                           <!-- 共用 UI を表示する Canvas -->
    <canvas name="sign" mode="world" pos="0 0.7 -0.8" size="1.6 1.2">  <!-- 空間の板 -->
      ...
    </canvas>
  </worldbody>
</wizengine>
```

- `<canvas>` は `<worldbody>` の直下に置きます。1 枚の Canvas の中に要素を平らに並べ、
  親子は `parent="親の id"` で表します（文書の順で、親を子より前に書く）。
- `id` は Canvas（または UI アセット）の中で一意です。省略すると、読み込みが空いている番号を振ります。
- `name` は、イベントのノードやアニメのキーが要素を指すときの名前です。
- 要素を描く順は文書の順で、後に書いた要素ほど手前に出ます。
- 種類が持たない属性・型に合わない値・知らない属性は、警告して読み飛ばします
  （読み込みそのものは失敗しません）。
- 既定値と同じ値は、保存のときに書き出しません。

## 2. Canvas の属性（`kCanvasAttrs`）

「効く表示方法」に無い表示方法では、その属性は効きません。値は持ったままで保存もされるので、
表示方法を戻せば元の値で効きます。Inspector も、今の表示方法に効く欄だけを出します。

| 属性 | 型 | 既定値 | 範囲 | 効く表示方法 | 意味 |
|---|---|---|---|---|---|
| `mode` | `overlay` / `camera` / `world` | `overlay` | — | すべて | 表示方法（下の 3 章） |
| `cameras` | 番号の並び（`"0 1"`） | 空 = 全カメラ | 0〜15 | すべて | 出すカメラ。無い番号・読めない番号を含むと、直すまでどのカメラにも出さない |
| `height` | 数 | 1080 | 16〜16384 | すべて | 基準の高さ（設計の画素） |
| `order` | 整数 | 0 | −10000〜10000 | overlay | Canvas どうしの重なり順。大きいほど手前で、同じ値なら後に足した物が手前 |
| `distance` | 数（m） | 1 | 0.01〜10000 | camera | カメラから板までの距離（6 章を参照） |
| `pos` | x y z（m） | 0 0 0 | ±10000 | world | 板の中心の位置 |
| `euler` | x y z（度） | 0 0 0 | — | world | 板の向き（回転の順はほかの物の euler と同じ） |
| `size` | 幅 高さ（m） | 1.6 0.9 | 0.01〜10000 | camera / world | 板の大きさ |
| `ui` | 名前 | 空 | — | すべて | 共用 UI の名前。書くと中身はその UI になる |

`ui` を書いた Canvas に子要素も書くと、子要素は警告して無視します（中身は UI の側が持つため）。
`ui` は Inspector の欄では変えられません。共用にする・ローカルにする操作だけが書き換えます。

## 3. 表示方法（`mode`）

| 表示方法 | どこに出るか | 物に隠れるか | 後処理が掛かるか |
|---|---|---|---|
| `overlay` | 映像の上に重ねる。映像の縦横比に合わせて広がる | 隠れない | 掛からない（後処理を切ったビューに描く） |
| `world` | 3D の空間に立つ板。`pos` / `euler` で置く | 隠れる | 掛かる |
| `camera` | カメラの正面、`distance` m 先に、カメラと同じ向きで付いてくる板 | 隠れる | 掛かる |

### 板の寸法の決まり（camera / world）

- 板の大きさは `size`（m）です。
- 中身は「高さ = `height`（設計の画素）、幅 = `height` × 板の縦横比（`size` の幅 ÷ 高さ）」として組みます。
  - 例: `size="1.6 1.2" height="1080"` のときは 1440 × 1080 の画素で組み、1 m は 900 画素です。
  - ビューの縦横比には依らないので、どのカメラから見ても同じ配置になります。
- 座標は overlay と同じく左上が原点で、x は右、y は下です。
- 板の表（字が読める側）は、板の +Z を向きます。`euler="0 0 0"` なら +Z 側から見て読めます。

### 板の注意

- **板は手前の物に隠れていても当たります**。シミュレート中のボタンは、物の陰になっていても
  押せます（隠れているかどうかの判定は持ちません）。
  - 押せないボタンを作りたくなければ、ボタンを物の陰に置かないでください（見本の看板は、
    ボタンを箱より上に置いています）。
- **ボタンの hover / pressed の色はカメラごとに分けません**。板の中身はすべてのカメラで 1 つなので、
  あるカメラのページでボタンに乗せると、同じ板を映すほかのカメラのページでも色が変わります。
  - overlay の Canvas はカメラごとに分かれています。
- 板にどの UI よりも手前に出す仕組みはありません。半透明の物どうしの前後は、カメラからの距離で決まります。

## 4. 後処理と板

板（camera / world）はメインのシーンに置くので、`<visual>` の後処理が掛かります。

- **被写界深度（dof）**: 板は奥行きを書かないので、板の後ろにある物の奥行きでぼけます。
- **TAA**: 速く動かすと残像が出ます。特に camera の板は、カメラを回すと残像が出ます。
- **トーンマップ・色作り・ブルーム**: overlay の UI と同じ色を指定しても、板の方は見え方が変わります。

overlay の UI には後処理は掛かりません（後処理を切った 2 枚目のビューに描きます）。
色をそろえたい・くっきり見せたい UI は overlay に置いてください。

## 5. 要素の種類と性質（`kProps`）

| 種類 | 何か | 持つ性質 |
|---|---|---|
| `<text>` | 字 | 共通 + 字の性質 |
| `<image>` | 画像（`file` が無ければ `color` の四角） | 共通 + `file` |
| `<button>` | 押せるボタン（背景 + 字） | 共通 + 字の性質 + `textColor` `file` `hover` `pressed` `enabled` |

| 性質 | 型 | 既定値 | 範囲 | 持つ種類 | 意味 |
|---|---|---|---|---|---|
| `anchor` | 左 上 右 下（0〜1） | 0 0 0 0 | 0〜1 | すべて | 親の矩形のどこに付けるか（左右・上下が違えば伸びる） |
| `pivot` | x y（0〜1） | 0 0 | 0〜1 | すべて | 自分のどの点を位置に合わせるか |
| `pos` | x y（設計の画素） | 0 0 | ±1000000 | すべて | アンカーからのずれ |
| `size` | 幅 高さ（設計の画素） | 100 100 | ±1000000 | すべて | 大きさ（アンカーが伸びる向きは、伸びた長さへの足し引き） |
| `color` | r g b a（リニア） | 1 1 1 1 | 0〜1 | すべて | 色。ボタンでは背景の色 |
| `alpha` | 数 | 1 | 0〜1 | すべて | 不透明度（子にも掛かる） |
| `visible` | true / false | true | — | すべて | 表示（false なら子も出ない） |
| `text` | 文字 | 空 | 4096 バイトまで | text / button | 字。改行は保存で `&#10;` になる |
| `font` | 名前 | 空 = 既定のフォント | — | text / button | `<font>` の名前 |
| `fontSize` | 数（設計の画素） | 32 | 1〜1024 | text / button | 字の大きさ |
| `align` | `left` / `center` / `right` | `left` | — | text / button | 横の揃え（ボタンの字は縦も中央） |
| `outline` | 数（字の大きさに対する割合） | 0 | 0〜0.2 | text / button | 縁取りの幅 |
| `outlineColor` | r g b a | 0 0 0 1 | 0〜1 | text / button | 縁取りの色 |
| `wrap` | true / false | false | — | text / button | 幅で折り返す |
| `textColor` | r g b a | 0.05 0.05 0.05 1 | 0〜1 | button | ボタンの字の色 |
| `file` | パス（assets/ からの相対） | 空 | 260 バイトまで | image / button | 画像（PNG / JPEG など） |
| `hover` | r g b a | 書かなければ背景を 25% 明るく | 0〜1 | button | ポインタが上にある間の背景の色 |
| `pressed` | r g b a | 書かなければ背景を 25% 暗く | 0〜1 | button | 押している間の背景の色 |
| `enabled` | true / false | true | — | button | 押せるか（false でも見た目は変えない） |

- 字は輪郭までの距離の画像（SDF）で描くので、拡大しても縁がなめらかです。
- フォントは同梱の Noto Sans JP（SIL OFL）が既定で、`<font>` で別のファイルを宣言できます。
- 画像が読めないときは白い四角で、フォントが読めないときは豆腐（四角）で描き、警告を出します。止めはしません。

## 6. `distance` と near クリップ（camera の板）

ビューの near クリップは、注視点までの距離の 1/10 です。ただし 0.5 cm〜10 cm に収めます
（`Renderer::setCamera`）。camera の板はカメラの正面に、カメラの向きと平行に置くので、
`distance` が今の near 以下だと**板全体が切れて見えません**。

- 注視点が 1 m より遠いときは、near は上限の 10 cm です。
- **`distance` は 0.1 m より大きくしてください**。
- 属性の下限（0.01 m）は、near より手前を許したままにしています。near はカメラの寄り方で
  変わるので、範囲の丸めでは「常に見える」を保証できないためです。

## 7. 共用 UI（`<ui>`）

- `<asset>` の `<ui name file="ui/x.xml">` は、ファイルを中身として共用する UI です。
  ファイルはルートが `<ui name>` で、中身の書き方は Canvas の子要素と同じです。
- `<ui name>` に子要素を直接書けば、このシーン専用の UI になります。
- `<canvas ui="名前">` で表示します。同じ UI を何枚の Canvas に出しても中身は 1 つなので、
  編集すると全部に効きます。
- 保存では、変わった共用 UI だけをファイルへ書きます。

## 8. UI のノード（イベント）

| ノード | 種類 | 欄 |
|---|---|---|
| `onUiClick` | トリガー | `target` = Canvas の番号（-1 = どれでも）、`element` = 要素の名前（空 = どれでも）。シミュレート中に、ボタンの上で押して離した 1 回 |
| `setUiProp` | アクション | `target` = Canvas（-1 = 押された Canvas）、`element` = 要素の名前（空 = 押された要素）、`prop` = 性質の名前、値 = 性質の型で決まる欄（数は `value`、x y z は `vec`、色は `color`、文字は `text`） |

- 書き換えは実行中だけで、設計値は変えません。シミュレートを止める・Reset すると元に戻ります。
- 一時停止の間に押したクリックは捨てます（再開した後に押したぶんだけ効きます）。

## 9. エディタでの操作（エディタモード × Editor Camera のページ）

- **追加**: アセットパネルの「🧱 作成」にある **Canvas**（映像の上に重ねる Canvas）と
  **World Canvas**（空間の板。エディタカメラの注視点に、カメラの方を向けて立てる）。
  要素は Inspector の「＋ 種類」か、一覧の右クリックで足します。
- **選択**: Scene タブの一覧で、Canvas か要素を選びます。
- **要素を動かす**: 要素を選ぶと、映像の中に枠と 8 つのつまみが出ます。
  - 枠の中をドラッグで移動、つまみで大きさを変えます（スナップは ⚙ のギズモの設定）。
  - 板の上の要素も同じように操作できます。枠はいちばん手前に描くので、手前の物やほかの板に
    隠れません。見えているつまみ（角と辺）は掴めます。枠の中の移動だけは、手前に別の板がある
    所では効きません（手前の板の中身を押したつもりで、奥の要素が動かないように）。
  - 板の一部がカメラの後ろに回っても、見えている部分の枠は出ます。
  - camera の板の上でドラッグ中にカメラを回すと、要素はカーソルの下の板の点に付いてきます。
- **world の板を動かす**: Canvas そのものを選ぶと、板の中心に移動 / 回転のギズモが出ます。
  - 拡縮のモードでは移動になります（大きさは Inspector の `size` で決めます）。
  - camera の板にはギズモは出ません（カメラに付くため）。
- **表示方法を変える**: Inspector の `mode`。
  - overlay から world に変えると、同じ操作で `pos` / `euler` を書いていなければ、追加と同じく
    エディタカメラの前に置きます。
  - camera から world、world のままのときは、今の `pos` / `euler` を残します。
- **中身を XML で直す**: Inspector の「📄 XML で編集」（その Canvas の中身だけ）。

## 10. 今は無いもの

- アニメ（`<anim>` / `<key>`）は読み書きだけできます。再生（自動再生・ノードからの再生 / 停止）は
  今後対応します。
- 隠れた板の当たりの判定、板ごとの後処理の切り替え、板をどの物よりも手前に出す指定。
- スライダーなど、ボタン以外の操作できる部品。
