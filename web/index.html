⚡︎ イベント設計 キャンバスを右クリックでノードを追加
右の ● （出力）から左の ● （入力）へドラッグで接続 ／ 線をクリックで切断 ／ 同じ入力に繋ぐと 張り替え ／ ノードは見出しをドラッグで移動、✕ で削除。未接続の入力は 0。入力ノードの名前がタイヤから渡される値（kappa = スリップ比、 alpha = スリップ角、fz = 荷重、mu = 摩擦係数、fxLo..fyHi = 力の 許される範囲）、出力ノードの fx / fy が車体へ掛かる力です。 変更はシミュレート中でもすぐ効きます（車両の走行状態は作り直し）。 右クリック: 何もない所でノードの追加と計算式の作成 / 削除、 ノードの上でそのノードの削除。付け先は Inspector の「車両」節。
トリガー（橙）右の ● からアクション（青）へドラッグで 接続 ／ 線をクリックで切断 ／ ノードは見出しをドラッグで移動、✕ で削除。 アクションの色・力はシミュレート中だけ効き、停止で設計値に戻ります。 対象が「(付けた相手)」のノードは、このアセットを付けたオブジェクト （またはトリガーが掴んだ / 触れた物）に働きます。アセットは Inspector の「イベント」から付けて初めて動きます。 右クリック: 何もない所でノードの追加とイベントの作成 / 削除、 ノードの上でそのノードの削除。
