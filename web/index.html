⚡︎ イベント設計
トリガー（橙）右の ● からアクション（青）へドラッグで 接続 ／ 線をクリックで切断 ／ ノードは見出しをドラッグで移動、✕ で削除。 アクションの色・力はシミュレート中だけ効き、停止で設計値に戻ります。
📄︎ シーン XML
MuJoCo 風のシーン文書（書式は CLAUDE.md の 「シーン文書（XML）」の章）。「✓ 適用」で現在の配置を置き換えます。 打ち間違いは警告としてステータスとコンソールに出ます。ファイルへの 保存は Assets パネルの 💾（assets/scenes/<名前>.xml）。
