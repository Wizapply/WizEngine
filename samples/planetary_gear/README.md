# 遊星歯車（`assets/scenes/planetary_gear.xml`）の部品メッシュの生成

`samples/` は見本シーンの素材を作るためのもの（エンジン本体のビルドにも実行にも
使わない）。`assets/models/planetary/*.glb` はここのスクリプトで作っている。

```bash
pip install manifold3d trimesh numpy scipy networkx
cd samples/planetary_gear
python3 gears.py      # 太陽歯車・遊星歯車・内歯車・遊星キャリヤ
```

- 歯数は CAD 図どおり: 太陽歯車 A 16・遊星歯車 B 22 × 4・内歯車 C 60・遊星キャリヤ D。
  同軸の条件 Zc = Za + 2 Zb と、等間隔に組める条件 (Za + Zc) / 4 が整数を
  スクリプトが確かめる。
- 歯形はインボリュート（圧力角 20°、標準歯車）。モジュール 5 mm・歯幅 25 mm。
  内歯車の歯溝は相手の外歯車の歯と同じ形で、どの歯もピッチ円上で歯厚を少し薄く
  （歯溝を少し広く）してすき間を取っている（約 0.19 mm）。
- `gears.py` の上の定数（モジュール・歯数・遊星の位置・歯の位相）が寸法の唯一の定義。
  シーンのボディの位置（遊星の中心 = 中心距離 × 角度）と歯車拘束の比
  （`ratio` = Za / Zb と Zb / Zc）も同じ値から出しているので、変えたらシーンも合わせる。
- 歯の位相: 遊星の位置 θ で太陽と内歯車は歯溝、遊星は歯を向ける（太陽の歯の中心 =
  180/Za + k 360/Za、遊星はボディを θ 回して置くのでローカルで k 360/Zb、内歯車の
  歯溝の中心 = k 360/Zc）。歯車拘束どおりに回る限りかみ合ったまま（太陽・内歯車・
  キャリヤをウィリスの式どおりに回した断面で、重なり 0・すき間 約 0.19 mm を確認）。
- 各部品はそのボディの座標系（歯車の中心 = 原点、回転軸 = +Z、歯幅の中央が z = 0）。
  太陽には入力軸（手前 +Z）、キャリヤには 4 本のピンと出力軸（奥 −Z）が付いている。
- 材質と CSG → .glb の道具は V6 の `samples/v6_engine/meshlib.py` を使う。
